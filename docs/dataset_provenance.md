### Cleaning applied (`src/models/train.py::load_training_data`)

1. Map labels to `negative / positive / neutral`, and drop unknown labels (0 dropped).
2. Drop empty comments (0 dropped).
3. Drop **every** row of a text that carries conflicting labels (2 rows dropped).
4. Drop normalised duplicates, keeping the first occurrence (23 rows dropped).
5. Result: **1,061 rows**: 548 positive, 414 negative, 99 neutral.

### Known limitations of this dataset

* Small and short: most comments are fragments of 5–9 words.
* One institution and one context. It may not represent other universities, disciplines or languages.
* The neutral class is small and heterogeneous. Many "neutral" comments are suggestions or wishes ("teacher should
  not pressurise the students") or carry a clear opinion. This partly explains the low neutral F1.
* Some labels look inconsistent on manual inspection, so the "most confident mistakes" in the Model Lab error
  analysis may reflect label noise.
* Informal spelling ("puntual", "theortical") is common.

## 2. Demonstration data (synthetic)

* File: `data/sample/demo_feedback.csv`, generated by `scripts/build_demo_dataset.py` (deterministic, seed 42).
* 89 rows: 84 reviews written for this project across four fictional courses and four anonymised instructors, plus
  3 deliberately invalid rows (2 empty, 1 non-alphabetic) and 2 exact duplicates, which demonstrate validation.
* Every row has `data_origin = synthetic-demo`, and the UI labels the dataset as synthetic.
* It is **never** used to train or evaluate the sentiment model.

## 3. Resources reviewed but not used

**EduRABSA** (<https://github.com/yhua219/edurabsa_dataset_and_annotation_tool>; paper arXiv:2508.17008).
This is a manually annotated education-review dataset for aspect-based sentiment tasks (6,500 reviews). Reasons it
was not integrated:

* The data is not in the GitHub repository. It is distributed separately through Zenodo
  (doi:10.5281/zenodo.16935017) and Hugging Face.
* Licence CC BY-NC-SA 4.0, which places non-commercial and share-alike obligations on redistribution.
* Its annotation scheme (aspect–opinion–category–sentiment quadruplets) does not map directly onto Sentiq's
  12-aspect teaching taxonomy. A reliable mapping and evaluation could not be built and validated within the
  project deadline.

So Sentiq reports **no aspect-level accuracy**. Integrating EduRABSA to evaluate aspect detection is the most
valuable next step.

## 4. Uploaded data

Users can upload their own CSVs. Uploads are processed in memory and are not written to disk, committed or logged.
Review text is never written to the application log.
